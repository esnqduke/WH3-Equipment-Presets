# WH3EP UI graphics

panel.png is a purpose-generated empty ornamental panel created with the built-in imagegen tool for this mod. It is used as a real native image resource, not a screenshot mockup; all labels remain dynamic.

Other PNGs are original code-drawn graphics generated by scripts/build-ui-skin.ps1 (run scripts/build-ui-skin.ps1 from the repository root). The script lives in scripts/, not inside this directory. They are committed assets and are not regenerated implicitly during ordinary pack builds. Generation also writes the interactive TWUI style templates and assigns new unique GUIDs.

Game equipment/follower icons are requested at runtime through the native ancillary IconPath and are not copied here. No user paths, campaign saves or registry data belong in these assets.

0.6.0 replaces panel.png with an empty texture derived directly from the approved UI reference (docs/design/approved-ui.png). It has small Cathay dragon title ornaments and a blank teal subtitle ribbon. All text, cards, icons and input/buttons are live components. Star/radio/checkbox graphics are code-drawn with active/hover/held/selected/disabled states. Shipped game glyphs remain runtime references; extracted glyphs under ignored research are QA inputs only.

0.7.15 reuses these textures for a two-row library card: six equipment and six
followers, 56px gold frames with 48px icon canvases and 8px gaps. The compact
heading is reduced to clear the divider. No flattened screenshot or baked preset
content replaces the live components. Offline previews are layout evidence only.

0.8.0 adds the reviewed bronze/iron and teal-enamel technical glyph family.
`build-unified-ui-icons.ps1` crops status, preset-archetype, entry, favorite,
search, empty-state and navigation marks to the checked TWUI slot sizes.
`build-unified-ui-buttons.ps1` generates role-sized text-free button surfaces
from the approved atlas; native TWUI text remains localized and dynamic.
`panel`, `preview_panel`, `result_panel`, row, input and progress surfaces keep
their existing empty-frame role. Item/follower art, rarity, hero portraits,
names and effects continue to come from WH3 at runtime.
